しほしけコンバーター（β版）

司法試験論文式の試験問題・出題の趣旨・採点実感を、法務省ウェブの公表PDFからテキストに変換します

短答式（司法試験・予備試験）の問題・正答PDFを年度別に保存したい場合は しほしけ短答ダウンローダー をどうぞ。

更新情報

    ヘルプ（よくある質問）

    はじめに

    このツールは何ですか？

    司法試験・予備試験の論文式の「試験問題」「出題の趣旨」「採点実感」を、法務省ウェブサイトで公表されているPDFから自動で抽出してテキスト化する、法務省非公式の個人開発ツールです。テキストにせず、原典PDFから該当ページだけを抜き出して保存することもできます。処理はすべてブラウザ内で行われ、登録やアカウントは不要です。

    基本的な使い方は？

    ①上の欄で「試験」「年度」「科目」「種類」を選ぶ → ②テキストが欲しいときは「変換実行」、PDFが欲しいときは「そのまま保存」の各ボタンを押す → ③テキストは「結果をコピー」または「.txt 保存」で持ち出します。②のPDF保存は、変換していなくてもそのまま押せます。

    「試験問題」「出題の趣旨」「採点実感」とは？

    「種類」で選ぶ3つは、いずれも法務省が公表する資料です。試験問題は本試験で配布された問題文、出題の趣旨はその問題で何を問うたのかを出題側が説明したもの、採点実感は実際の答案を採点しての所感（よくある誤り・評価の分かれ目など）です。趣旨と実感は例年9〜11月頃に公表されます。予備試験に採点実感はなく、試験問題と出題の趣旨の2種類です。

    対応している年度・科目は？

    画面上部の「試験」で司法試験・予備試験を切り替えられます。
    ・司法試験: 平成22年から最新年度まで。基本7科目（憲法・行政法・民法・商法・民訴・刑法・刑訴）と、選択科目8科目（倒産法・租税法・経済法・知的財産法・労働法・環境法・国際関係法（公法系）・国際関係法（私法系））の各第１問・第２問。
    ・予備試験: 平成23年から最新年度まで。基本7科目・法律実務基礎科目（民事・刑事）・選択科目8科目・一般教養科目（令和3年以前）。種類は試験問題と出題の趣旨のみです。予備試験は複数科目をまとめたPDF（「憲法・行政法」など）で公表されますが、選んだ科目だけを自動で切り出します。

    キーワードから年度を探せますか？

    画面右上の「全文検索」から探せます。科目を選んでキーワードを入れると、その科目の全年度について、試験問題・出題の趣旨・採点実感の本文を検索し、該当した年度をカードで一覧します。カードを押すと、その年度・科目・種類が画面の選択欄に入るので、そのまま「変換実行」や各種保存に進めます。検索は事前変換済みデータに対して行うので、法務省ウェブサイトへのアクセスは発生しません（変換データが無い年度は検索対象外です）。

    新しい年度はいつ使えるようになりますか？

    毎週月曜の朝に法務省ウェブサイトを自動巡回しています。試験問題（例年8月頃）、出題の趣旨・採点実感（例年9〜11月頃）が法務省ウェブに掲載されると、1週間以内に自動で追加され、「更新情報」欄でお知らせします。

    テキストに変換する（メイン機能）

    「変換実行」を押すと何が起きますか？

    法務省の原典PDFを取得し、ブラウザ内で解析して、改行や段落を読める形に復元したテキストを「結果」欄に表示します。完了すると「結果をコピー」と「.txt 保存」が押せるようになります。処理の進み具合は進捗バーと「ログ」タブで確認できます。

    出力形式の「ノーマル」と「Scrapbox記法」の違いは？

    ノーマルは装飾のないプレーンテキストです。Scrapbox記法を選ぶと、見出しが [* ]・[** ] で装飾され、#司法試験 などのタグ行が付きます。どちらも冒頭に出典（法務省の原典PDFのURL）が入ります。Scrapbox（ノートアプリ）に貼り付けないのであれば、ノーマルで十分です。

    そのまま保存する（変換不要）

    「原典PDF保存」は何をしますか？

    選択中の年度・科目・種類について、法務省の原典PDFから該当するページだけを抜き出したPDFを保存します。各ページの右下にファイル名、左下に出典と、試験問題・出題の趣旨・採点実感それぞれの原典PDFへのクリック可能なリンクを印字します。変換実行をしていなくても、押せば自動で取得・処理されます。

    「一式zip保存」は何をしますか？

    選択中の年度・科目について、試験問題・出題の趣旨・採点実感の3点の抜粋PDFを「[年度]司法試験[科目]一式」フォルダにまとめ、zipで保存します。処理済みの種類は再利用されるため、変換実行のあとに押すと速く完了します。未掲載の種類がある年度では、取得できた分だけが入ります。

    「LLM用に保存」は何をしますか？

    選択中の年度・科目について、試験問題・出題の趣旨・採点実感を1つのMarkdownファイルにまとめて保存します。冒頭に「これは司法試験論文式の過去問である」というメタ情報と出典（原典PDFのURL）が入るので、ChatGPTやClaudeなどのLLMにそのまま貼り付け・添付して、答案の添削や解説を依頼するのに使えます。

    うまくいかないとき

    エラーが出ます／PDFを取得できません

    多くは、法務省ウェブサイト側でページの構成やリンクが変わったか、一時的な通信エラーです。まず「ログ」タブでメッセージを確認し、少し時間をおいて試し直してください。特定の年度・科目だけが必ず失敗する場合はツール側の不具合の可能性が高いので、年度・科目・種類とログの内容を添えて GitHub の Issue からお知らせください。

    処理に時間がかかります／2回目が速いのはなぜ？

    原典PDFの取得と解析に時間がかかるためで、ページ数の多い年度では数十秒かかることがあります。一度処理した年度・科目・種類は結果を一時的に保持するので、2回目以降や「一式zip保存」「LLM用に保存」は速く終わります。この保持はページを再読み込みすると消えます。

    出力が原典と違う気がします

    PDF解析による自動変換のため、改行位置や段落の区切りなどに誤りが生じることがあります。学習には原典PDFをあわせてご確認ください。おかしな箇所があれば GitHub の Issue からお知らせください。

    別々の科目や問で、同じ内容が出力されます

    原典の採点実感が問ごとに分かれていない年度・科目（選択科目や平成期の多く）では、科目全体（第１問・第２問の両方を含む）を出力します。また平成22年の民事系は2問構成で、第１問が商法、第２問が民法・民事訴訟法の総合問題のため、民法と民訴の試験問題・出題の趣旨は同じ第２問になります（採点実感は科目別に公表されているため別々です）。いずれも原典の構造どおりの出力です。

    抜粋PDFの先頭ページに前の問題の終わりが入っています

    抜粋はページ単位で行うため、同じページ内で前の問題が終わり次の問題が始まっている場合、その部分が含まれます。

    予備試験の一般教養科目で、出題の趣旨が変換できません

    予備試験の一般教養科目については、法務省が出題の趣旨を公表していないためです（試験問題は変換できます）。それ以外の科目・年度でまれに変換できない場合は、原典PDFから文字を取り出せない可能性があるので、「原典PDF保存」をご利用ください（変換を試みると、その旨をお知らせします）。

    データの扱いと権利

    データはどこから取得していますか？

    テキスト変換は、まず本ツールが用意している事前変換済みデータ（GitHub リポジトリに置いてある年度・科目ごとのJSON）を探し、あればそれを整形して表示します。この場合、原典PDFの取得もPDF解析も行いません。事前変換データが無い場合（新年度の掲載直後など）だけ、原典PDFを取得してブラウザ内で解析します。

    原典PDF保存・一式zip保存・LLM用に保存は、PDFそのものが必要なため、いずれも原典PDFを取得します。

    原典PDFを取得する場合は、法務省ウェブサイトへの負荷を最小限にするため、原則として中継サーバー（Cloudflare Worker）に保管済みのPDFを使います。まだ保管されていないPDFだけを法務省から取得し、以後はその保管分を配信します。過去問PDFは公表後に内容が変わらないため、同じPDFを法務省へ繰り返し取りに行くことはありません。取得元は「ログ」タブで確認できます。

    取得したPDFや変換結果はどこかに送信されますか？

    PDFの解析・整形・保存はすべてお使いのブラウザ内で行われ、変換結果や保存したファイルが外部に送られることはありません。アカウント登録もアクセス解析もありません。ブラウザから法務省ウェブサイトへ直接アクセスできない制約（CORS）があるため、原典PDFの取得だけは上記の中継サーバーを通りますが、中継するのは法務省サイト配下のURLだけで、そこで扱うのは公表済みのPDFのみです。

    著作権は大丈夫ですか？学内などで共有してもよいですか？

    本ツールは原則 MIT License で公開しています。ソースコードは、著作権表示とライセンス文を残すことを条件に、自由に利用・改変・再配布できます。

    ただし、試験問題・出題の趣旨・採点実感そのものは法務省ウェブサイトの公表資料に由来するため、MIT License の対象外です。これらには「公共データ利用規約（PDL1.0）」が適用され、出典の記載と加工した旨の表示を条件に、複製・共有・加工が認められています。本ツールの出力（テキスト・抜粋PDF）には出典・加工表示が自動で付くので、そのまま保持したうえで学内などで共有してください。

    全文検索

    選んだ科目について、全年度の本文をキーワードで検索します。結果のカードを押すと、その年度・科目・種類が画面の選択欄に入ります。検索は事前変換済みデータに対して行うため、まだ変換データが無い年度（新年度の掲載直後など）は対象外です。

    キーワードを入力して「検索」を押してください。
